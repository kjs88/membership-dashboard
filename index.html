🔥 Firebase 연동 설정
실시간 공유를 위해 Firebase Realtime Database URL을 입력하세요.
한 번만 설정하면 이후에는 자동으로 연결됩니다.
1. console.firebase.google.com → 프로젝트 생성
2. Realtime Database → 데이터베이스 만들기 → 테스트 모드
3. 아래와 같은 URL을 복사해서 붙여넣기
https://your-project-default-rtdb.firebaseio.com
올바른 Firebase URL을 입력해주세요.
